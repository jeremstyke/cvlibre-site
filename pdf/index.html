Pourquoi vos documents sont refusés

  • Le fichier est trop lourd : un scan ou une photo de téléphone dépasse vite 3 à 10 Mo, alors que l'ANTS accepte 1 Mo pour une carte grise.
  • Le format n'est pas accepté : les photos d'iPhone sont souvent en HEIC, un format refusé par la plupart des sites.
  • Le nom du fichier pose problème : accents, espaces et caractères spéciaux peuvent bloquer l'envoi.
  • Le recto et le verso sont séparés : beaucoup de démarches attendent un seul fichier par pièce.

Vos documents restent chez vous

Avis d'imposition, RIB, pièce d'identité : ce sont des documents sensibles. Ici, tout le traitement se fait directement dans votre navigateur. Aucun fichier n'est envoyé sur un serveur, rien n'est stocké. Vous pouvez même couper Internet une fois la page chargée : l'outil continue de fonctionner.

Vos papiers prêts pour la prochaine fois

Gardez vos fichiers déjà au bon format (pièce d'identité recto verso, RIB, justificatif de domicile) dans Mes documents. Ils restent sur votre appareil, sans compte, et vous les retrouvez dans chaque outil.

Questions fréquentes

Est-ce vraiment gratuit ?

Oui. Tous les outils sont gratuits, sans inscription, sans limite de nombre de fichiers et sans filigrane.

Mes documents sont-ils envoyés quelque part ?

Non. Le traitement se fait sur votre appareil, dans votre navigateur. Vos fichiers ne sont jamais transmis ni stockés sur un serveur.

Est-ce un site officiel ?

Non. PDF Démarches est un site indépendant qui aide à préparer ses fichiers. Vos démarches se font toujours sur les sites officiels (caf.fr, ants.gouv.fr, impots.gouv.fr...).

Ça marche sur téléphone ?

Oui, sur iPhone comme sur Android, directement dans le navigateur. Rien à installer.
