🔄 PDF drehen

Scan auf dem Kopf oder quer? Drehen Sie alle Seiten Ihrer PDFs um eine Viertel- oder halbe Drehung.

...

So geht es

  1. Wählen Sie Ihre Dateien über den Knopf aus oder ziehen Sie sie in das Feld.
  2. Wählen Sie die Drehung: 90° rechts, 90° links oder 180°.
  3. Klicken Sie auf „Drehen" und dann auf „Herunterladen".

Warum CVLibre PDF

  • Ihre Dateien bleiben bei Ihnen: Nichts wird auf einen Server hochgeladen. Ideal für Ausweis, Vertrag oder Gehaltsabrechnung.
  • Kostenlos, ohne Limit: keine Anmeldung, kein Wasserzeichen, keine Höchstzahl an Dateien.
  • Auf Handy und Computer: nichts zu installieren, iPhone-Fotos (HEIC) werden unterstützt.

Häufige Fragen

Ist PDF drehen kostenlos?

Ja, komplett kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Dateilimit.

Werden meine Dateien ins Internet hochgeladen?

Nein. PDF drehen läuft direkt in Ihrem Browser: Ihre Dateien werden auf Ihrem Gerät verarbeitet und nie an einen Server gesendet oder dort gespeichert.

Funktioniert es auf dem Handy?

Ja, auf iPhone und Android, im Browser. Nichts zu installieren.
