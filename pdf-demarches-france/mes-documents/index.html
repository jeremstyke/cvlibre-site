Mes documents

Vos fichiers déjà préparés, prêts pour la prochaine démarche. Ils sont gardés uniquement sur cet appareil, dans votre navigateur : pas de compte, rien n'est envoyé sur Internet.

Chargement...

Comment ça marche

  1. Préparez un fichier avec n'importe quel outil du site (réduire, fusionner, photo en PDF...).
  2. Sous le bouton « Télécharger », touchez « 💾 Garder dans Mes documents ».
  3. La prochaine fois, dans n'importe quel outil, touchez « 📁 Prendre dans Mes documents » : votre fichier est déjà prêt.

Bon à savoir

  • Vos documents restent sur cet appareil et ce navigateur. Ils ne suivent pas d'un téléphone à un ordinateur.
  • Si vous effacez les données de navigation, ou en navigation privée, ils disparaissent. Gardez toujours une copie de vos originaux.
  • Sur iPhone, Safari peut effacer les données d'un site après plusieurs jours sans visite. Ne comptez pas sur cet espace comme seul exemplaire.
  • Sur un appareil partagé, pensez à tout supprimer après usage.

Questions fréquentes

Mes documents sont-ils envoyés sur un serveur ?

Non. Ils sont enregistrés dans le stockage de votre navigateur, sur votre appareil. Personne d'autre, pas même nous, ne peut y accéder.

Faut-il créer un compte ?

Non, aucun compte. C'est justement ce qui garantit que vos documents ne quittent pas votre appareil.
